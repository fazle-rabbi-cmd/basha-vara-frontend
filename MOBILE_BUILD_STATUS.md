## Quick Start (Development Build)

If you want to test the app quickly with live reload:

```bash
# Terminal 1: Start backend
cd E:\basha-vara\backend
npm run start:dev

# Terminal 2: Start frontend
cd E:\basha-vara\frontend
npm run dev

# Terminal 3: Sync and open
cd E:\basha-vara\frontend
npx cap sync android
npx cap open android
```

Then in Android Studio:
1. Wait for Gradle sync
2. Select emulator or device
3. Click Run button (▶️)

---

## Quick Start (Production Build)

If you want to create a standalone APK:

```bash
# Build frontend
cd E:\basha-vara\frontend
npm run build

# Sync to Android
npx cap sync android

# Open Android Studio
npx cap open android
```

Then in Android Studio:
1. Wait for Gradle sync
2. Build → Build Bundle(s) / APK(s) → Build APK(s)
3. Locate and install the APK

## Important Notes

### Development vs Production URLs

**Development:**
- Backend: `http://localhost:4000/api/v1`
- Frontend: `http://localhost:3000`
- App connects to dev server via URL in capacitor.config.ts

**Production:**
- Backend: Your deployed backend URL (e.g., from Render/Railway)
- Frontend: Your deployed frontend URL (e.g., from Vercel)
- App uses bundled files and API URL from environment

### Backend Required

For the app to work:
- Development: Backend must be running locally
- Production: Backend must be deployed and accessible

### Database Required

For the app to function:
- Development: Local PostgreSQL via Docker
- Production: Supabase or other cloud database
